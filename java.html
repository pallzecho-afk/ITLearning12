LEVEL 1

Java Dasar

01

PENGENALAN

Apa Itu Java?

Java adalah bahasa pemrograman yang populer dan digunakan untuk membuat berbagai jenis aplikasi. Java menggunakan konsep Object Oriented Programming atau OOP.

02

PROGRAM PERTAMA

Hello World

Berikut adalah contoh program Java sederhana. 

public class Main {

    public static void main(String[] args) {

        System.out.println("Hello World");

    }

}
03

OUTPUT

System.out.println()

Digunakan untuk menampilkan teks ke layar. 

System.out.println("Halo Dunia");
04

VARIABLE

Variabel

Variabel digunakan untuk menyimpan data. 

String nama = "Opal";

System.out.println(nama);
05

DATA TYPE

Tipe Data

int

Menyimpan bilangan bulat.

double

Menyimpan bilangan desimal.

String

Menyimpan teks.

boolean

Menyimpan nilai true atau false.

06

OPERATOR

Operator Matematika

int angka1 = 10;
int angka2 = 5;

int hasil = angka1 + angka2;

System.out.println(hasil);
07

INPUT

Input dari User

import java.util.Scanner;

Scanner input = new Scanner(System.in);

System.out.print("Masukkan nama: ");

String nama = input.nextLine();

System.out.println("Halo " + nama);
08

CONDITION

if dan else

int umur = 18;

if (umur >= 18) {

    System.out.println("Dewasa");

} else {

    System.out.println("Belum Dewasa");

}
09

CONDITION

Switch

int hari = 1;

switch (hari) {

    case 1:
        System.out.println("Senin");
        break;

    case 2:
        System.out.println("Selasa");
        break;

    default:
        System.out.println("Hari lainnya");

}
