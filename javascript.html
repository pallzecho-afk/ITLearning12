JavaScript dari Dasar

JavaScript digunakan untuk membuat website menjadi lebih interaktif dan dinamis. Kamu dapat membuat tombol, animasi, perhitungan, dan berbagai fitur lainnya.

Apa Itu JavaScript?

JavaScript adalah bahasa pemrograman yang sering digunakan untuk membuat halaman website menjadi interaktif.

Menampilkan Output

Salah satu cara sederhana untuk menampilkan informasi adalah menggunakan console.log().

const
