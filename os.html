LEVEL 1

Dasar Operating System

01

PENGENALAN

Apa Itu Operating System?

Operating System atau Sistem Operasi adalah perangkat lunak utama yang mengatur dan mengelola perangkat keras serta perangkat lunak pada komputer.

Sistem operasi menjadi penghubung antara pengguna, aplikasi, dan perangkat keras.

02

FUNGSI

Fungsi Operating System

🧠

Mengelola CPU

Mengatur proses yang berjalan.

💾

Mengelola Memori

Mengatur penggunaan RAM.

📁

Mengelola File

Mengatur penyimpanan data.

🔌

Mengelola Perangkat

Menghubungkan hardware.

03

KOMPONEN

Kernel

Kernel adalah bagian inti dari sistem operasi. Kernel bertugas menghubungkan software dengan hardware.

Contoh tugas Kernel:
  • Mengelola CPU
  • Mengelola RAM
  • Mengelola perangkat keras
  • Mengelola proses sistem
04

INTERFACE

GUI dan CLI

GUI

Graphical User Interface menggunakan tampilan visual seperti icon, menu, tombol, dan jendela.

Contoh: Windows

CLI

Command Line Interface menggunakan perintah teks melalui terminal.

Contoh: Linux Terminal
05

STARTUP

Booting

Booting adalah proses ketika komputer dinyalakan sampai sistem operasi siap digunakan.

Power
→
BIOS / UEFI
→
Bootloader

Operating System

LEVEL 2

Jenis Operating System

06

DESKTOP

Windows

Windows adalah sistem operasi yang banyak digunakan pada komputer dan laptop.

Windows 10 Windows 11 Windows Server
07

OPEN SOURCE

Linux

Linux adalah sistem operasi yang memiliki banyak distribusi dan sering digunakan untuk server, jaringan, dan pengembangan.

Ubuntu Debian Fedora Linux Mint Kali Linux
08

APPLE

macOS

macOS adalah sistem operasi yang digunakan pada komputer Mac.

09

MOBILE

Android

Android adalah sistem operasi yang banyak digunakan pada smartphone dan perangkat mobile.

10

GOOGLE

ChromeOS

ChromeOS merupakan sistem operasi yang digunakan pada perangkat Chromebook.

LEVEL 3

Operating System Lanjutan

11

FILE

File Management

Sistem operasi mengatur bagaimana file disimpan, dibuka, dipindahkan, dan dihapus.

File Folder Directory Path
12

MEMORY

Memory Management

Operating System mengatur penggunaan RAM agar beberapa aplikasi dapat berjalan secara bersamaan.

13

PROCESS

Process dan Thread

Process

Program yang sedang dijalankan oleh sistem operasi.

Thread

Bagian kecil dari sebuah process yang dapat menjalankan tugas.

14

CPU

CPU Scheduling

CPU Scheduling adalah cara sistem operasi menentukan process mana yang akan menggunakan CPU terlebih dahulu.

FCFS Priority Round Robin
15

ACCOUNT

User Account

User Account digunakan untuk membedakan pengguna dan mengatur hak akses.

Administrator Standard User Guest
16

HARDWARE

Driver

Driver adalah software yang memungkinkan sistem operasi berkomunikasi dengan perangkat keras.

GPU Driver Audio Driver Network Driver Printer Driver
17

STORAGE

File System

File System adalah sistem yang digunakan untuk mengatur data pada media penyimpanan.

NTFS FAT32 exFAT ext4
18

VIRTUALIZATION

Virtual Machine

Virtual Machine memungkinkan satu komputer menjalankan sistem operasi lain secara virtual.

VirtualBox VMware Hyper-V
19

SECURITY

Keamanan Operating System

  • Gunakan password yang kuat.
  • Update sistem operasi secara rutin.
  • Gunakan antivirus atau perlindungan keamanan.
  • Jangan menjalankan file dari sumber tidak terpercaya.
  • Lakukan backup data secara rutin.
