LEVEL 1

SQL Dasar

01

PENGENALAN

Apa Itu SQL?

SQL atau Structured Query Language adalah bahasa yang digunakan untuk berkomunikasi dengan database.

Dengan SQL, kita dapat membuat database, menyimpan data, mengubah data, menghapus data, dan mengambil data.

02

DASAR DATABASE

Database, Table, Row dan Column

Database

Kumpulan data yang terorganisir.

Table

Tempat data disimpan dalam bentuk tabel.

Row

Satu baris data dalam tabel.

Column

Bagian kategori atau atribut data.

03

DATABASE

CREATE DATABASE

Perintah CREATE DATABASE digunakan untuk membuat database baru. 

CREATE DATABASE sekolah;
04

TABLE

CREATE TABLE

CREATE TABLE siswa (

    id INT PRIMARY KEY,
    nama VARCHAR(100),
    kelas VARCHAR(20)

);
05

DATA

INSERT INTO

INSERT INTO digunakan untuk menambahkan data baru ke dalam tabel. 

INSERT INTO siswa

(id, nama, kelas)

VALUES

(1, 'Opal', 'XII TKJ');
06

QUERY

SELECT

SELECT digunakan untuk mengambil atau menampilkan data dari tabel. 

SELECT *

FROM siswa;
07

FILTER

WHERE

SELECT *

FROM siswa

WHERE kelas = 'XII TKJ';
08

SORTING

ORDER BY

SELECT *

FROM siswa

ORDER BY nama ASC;

UPDATE

UPDATE Data

UPDATE siswa

10

DELETE

DELETE FROM siswa

WHERE id = 1;
11

LIMIT

LIMIT

SELECT *

FROM siswa

12

FUNCTION

Aggregate Function

COUNT()

Menghitung jumlah data.

SUM()

Menjumlahkan data angka.

AVG()

Menghitung nilai rata-rata.

MAX()

Mencari nilai terbesar.

MIN()

Mencari nilai terkecil.

13

GROUPING

GROUP BY

SELECT kelas,

COUNT(*)

FROM siswa

GROUP BY kelas;
14

FILTER

HAVING

SELECT kelas,

COUNT(*)

FROM siswa

GROUP BY kelas

HAVING COUNT(*) > 5;
15

JOIN

INNER JOIN

JOIN digunakan untuk menggabungkan data dari beberapa tabel. 

SELECT siswa.nama,

kelas.nama_kelas

FROM siswa

INNER JOIN kelas

ON siswa.id_kelas = kelas.id;
🟣

LEVEL 3

SQL Lanjutan

16

KEY

Primary Key

Primary Key adalah kolom yang memiliki nilai unik untuk setiap data. 

CREATE TABLE siswa (

    id INT PRIMARY KEY,

    nama VARCHAR(100)

);
17

KEY

Foreign Key

Foreign Key digunakan untuk menghubungkan satu tabel dengan tabel lainnya. 

FOREIGN KEY

(id_kelas)

REFERENCES kelas(id);
18

JOIN

LEFT JOIN

SELECT *

FROM siswa

LEFT JOIN kelas

ON siswa.id_kelas = kelas.id;
19

DATABASE

MySQL

MySQL adalah salah satu sistem database yang paling populer dan sering digunakan bersama PHP.

BEST PRACTICE

Keamanan Database

  • Gunakan password database yang kuat.
  • Batasi akses pengguna database.
  • Gunakan parameterized query.
  • Lakukan backup database secara rutin.
  • Jangan menyimpan password dalam bentuk teks biasa.
