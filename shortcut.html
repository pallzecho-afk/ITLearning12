WINDOWS

Shortcut Windows

Ctrl+C

Copy

Menyalin teks atau file.

Ctrl+V

Paste

Menempelkan hasil salinan.

Ctrl+X

Cut

Memotong teks atau file.

Ctrl+Z

Undo

Membatalkan tindakan terakhir.

Ctrl+Y

Redo

Mengulangi tindakan yang dibatalkan.

Ctrl+A

Select All

Memilih semua item.

Alt+Tab

Switch Window

Berpindah antar aplikasi.

Alt+F4

Close

Menutup aplikasi aktif.

Win+D

Desktop

Menampilkan desktop.

Win+E

File Explorer

Membuka File Explorer.

Win+L

Lock

Mengunci komputer.

Win+R

Run

Membuka kotak Run.

🐧

LINUX

Shortcut Linux

Ctrl+Alt+T

Terminal

Membuka terminal.

Alt+F2

Command

Membuka perintah cepat pada desktop tertentu.

Alt+Tab

Switch App

Berpindah antar aplikasi.

Ctrl+C

Copy

Menyalin teks atau file.

Ctrl+V

Paste

Menempelkan hasil salinan.

Ctrl+Alt+Del

Logout Menu

Membuka menu logout pada beberapa desktop environment.

MACBOOK

Shortcut MacBook

⌘+C

Copy

Menyalin item.

⌘+V

Paste

Menempelkan item.

⌘+X

Cut

Memotong teks atau item.

⌘+Z

Undo

Membatalkan tindakan terakhir.

⌘+Space

Spotlight

Membuka pencarian Spotlight.

⌘+Tab

Switch App

Berpindah antar aplikasi.

⌘+Q

Quit App

Menutup aplikasi sepenuhnya.

⌘+W

Close Window

Menutup jendela aktif.

MICROSOFT OFFICE

Shortcut Microsoft Word

Ctrl+B

Bold

Membuat teks menjadi tebal.

Ctrl+I

Italic

Membuat teks menjadi miring.

Ctrl+U

Underline

Memberikan garis bawah pada teks.

Ctrl+S

Save

Menyimpan dokumen.

Ctrl+P

Print

Membuka menu cetak.

Ctrl+F

Find

Mencari teks dalam dokumen.

Ctrl+H

Replace

Mengganti teks tertentu.

Ctrl+E

Center

Membuat teks rata tengah.

Ctrl+L

Align Left

Membuat teks rata kiri.

Ctrl+R

Align Right

Membuat teks rata kanan.

Ctrl+J

Justify

Membuat teks rata kiri dan kanan.

Ctrl+A

Select All

Memilih seluruh isi dokumen.
