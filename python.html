Apa itu Python?

Python adalah bahasa pemrograman tingkat tinggi yang terkenal karena sintaksnya sederhana dan mudah dipahami.

Python digunakan dalam berbagai bidang seperti web development, data science, automation, dan artificial intelligence.

CONDITIONAL

if, elif, else

Conditional digunakan untuk membuat keputusan berdasarkan kondisi.

Python 
nilai = 80

if nilai >= 75:
    print("Lulus")

else:
    print("Belum Lulus")

Python

LOOPING

While Loop

While akan menjalankan kode selama kondisi bernilai True.

Python
