LEVEL 1

C Dasar

01

PENGENALAN

Apa Itu Bahasa C?

Bahasa C adalah bahasa pemrograman tingkat menengah yang terkenal karena cepat, efisien, dan dekat dengan sistem komputer. Bahasa C sering digunakan untuk mempelajari dasar pemrograman.

02

PROGRAM PERTAMA

Hello World

Berikut contoh program pertama menggunakan Bahasa C. 

#include <stdio.h>

int main() {

    printf("Hello World");

    return 0;

}
03

OUTPUT

printf()

Fungsi printf() digunakan untuk menampilkan teks atau nilai ke layar. 

printf("Halo Dunia");
04

VARIABLE

Variabel

Variabel digunakan untuk menyimpan data di dalam program. 

int umur = 18;

printf("%d", umur);
05

DATA TYPE

Tipe Data

int

Menyimpan bilangan bulat.

float

Menyimpan bilangan desimal.

double

Menyimpan angka desimal dengan presisi lebih tinggi.

char

Menyimpan satu karakter.

06

OPERATOR

Operator Matematika

int a = 10;
int b = 5;

int hasil = a + b;

printf("%d", hasil);
07

INPUT

scanf()

Fungsi scanf() digunakan untuk menerima input dari pengguna. 

int umur;

printf("Masukkan umur: ");

scanf("%d", &umur);

printf("Umur kamu %d", umur);
08

CONDITION

if dan else

int umur = 18;

if (umur >= 18) {

    printf("Dewasa");

} else {

    printf("Belum Dewasa");

}
09

CONDITION

switch

int hari = 1;

switch (hari) {

    case 1:
        printf("Senin");
        break;

    case 2:
        printf("Selasa");
        break;

    default:
        printf("Hari lainnya");

}
🔵

LEVEL 2

C Menengah

10

LOOP

for Loop

for (int i = 1; i <= 5; i++) {

    printf("%d\n", i);

}
11

LOOP

while Loop

int angka = 1;

while (angka <= 5) {

    printf("%d\n", angka);

    angka++;

}
12

LOOP

do while

int angka = 1;

do {

    printf("%d\n", angka);

    angka++;

} while (angka <= 5);
13

FUNCTION

Function

Function digunakan untuk mengelompokkan kode agar program lebih rapi. 

void salam() {

    printf("Halo!");

}
14

FUNCTION

Parameter

void salam(char nama[]) {

    printf("Halo %s", nama);

}
15

ARRAY

Array

int angka[] = {

    10,
    20,
    30

};

printf("%d", angka[0]);
16

STRING

String

char nama[] = "Opal";

printf("%s", nama);
🟣

LEVEL 3

C Lanjutan

17

POINTER

Apa Itu Pointer?

Pointer adalah variabel yang digunakan untuk menyimpan alamat memori dari variabel lain. 

int angka = 10;

int *pointer = &angka;

printf("%d", *pointer);
18

STRUCT

Structure

Struct digunakan untuk menggabungkan beberapa jenis data menjadi satu struktur. 

struct Mahasiswa {

    char nama[50];

    int umur;

};
19

FILE

File Handling

Bahasa C dapat digunakan untuk membaca dan menulis file. 

FILE *file;

file = fopen("data.txt", "w");

fprintf(file, "Halo Dunia");

fclose(file);
20

MEMORY

Dynamic Memory

Dynamic memory memungkinkan program menggunakan memori saat program berjalan. 

#include <stdlib.h>

int *angka;

angka = malloc(sizeof(int));

*angka = 10;

free(angka);
