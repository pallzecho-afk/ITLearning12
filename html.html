HTML dari Dasar

HTML adalah bahasa dasar yang digunakan untuk membuat struktur sebuah website. Pelajari elemen, tag, teks, gambar, link, form, tabel, dan masih banyak lagi.

Mulai Belajar ↓
🟢

LEVEL 1

HTML Dasar

01

PENGENALAN

Apa Itu HTML?

HTML merupakan singkatan dari HyperText Markup Language. HTML digunakan untuk membuat struktur dan isi sebuah halaman website.

02

DASAR

Struktur Dasar HTML

Sebuah halaman HTML biasanya memiliki struktur dasar seperti berikut. 

<!DOCTYPE html>
<html>

<head>
    <title>>Website Saya</title>
</head>

<body>

    <h1>Halo Dunia</h1>

</body>

</html>
03

DASAR

Tag HTML

Tag adalah bagian penting dalam HTML. Sebagian besar tag memiliki tag pembuka dan tag penutup. 

<p>

Isi teks berada di sini

</p>
04

TEXT

Heading

Heading digunakan untuk membuat judul atau subjudul pada halaman website. 

<h1>Heading 1</h1>
<h2>Heading 2</h2>
<h3>Heading 3</h3>
<h4>Heading 4</h4>
<h5>Heading 5</h5>
<h6>Heading 6</h6>
05

TEXT

Paragraph

Tag paragraph digunakan untuk membuat sebuah paragraf. 

<p>

Ini adalah sebuah paragraf.

</p>
06

TEXT

Formatting Text

<strong>

Membuat teks penting

<b>

Membuat teks tebal

<i>

Membuat teks miring

<u>

Membuat teks bergaris bawah

07

LINK

Hyperlink

Tag a digunakan untuk membuat link. 

<a href="https://google.com">

Google

</a>
08

IMAGE

Menampilkan Gambar

Tag img digunakan untuk menampilkan gambar pada website. 

<img
src="gambar.jpg"
alt="Deskripsi Gambar">
09

LIST

Ordered List

Ordered List digunakan untuk membuat daftar yang memiliki nomor. 

<ol>

    <li>HTML</li>
    <li>CSS</li>
    <li>JavaScript</li>

</ol>
10

LIST

Unordered List

<ul>

    <li>HTML</li>
    <li>CSS</li>
    <li>JavaScript</li>

</ul>
