LEVEL 1

C++ Dasar

01

PENGENALAN

Apa Itu C++?

C++ adalah bahasa pemrograman yang dikembangkan dari bahasa C. Bahasa ini terkenal karena memiliki performa tinggi dan mendukung Object-Oriented Programming.

02

PROGRAM PERTAMA

Hello World

Program pertama yang biasanya dibuat ketika belajar bahasa pemrograman adalah program Hello World. 

#include <iostream>

using namespace std;

int main() {

    cout << "Hello World";

    return 0;

}
03

OUTPUT

cout

cout digunakan untuk menampilkan teks atau data ke layar. 

cout << "Halo Dunia";
04

VARIABLE

Variabel

Variabel digunakan untuk menyimpan informasi atau data dalam program. 

int umur = 18;

cout << umur;
05

DATA TYPE

Tipe Data

int

Menyimpan bilangan bulat.

float

Menyimpan bilangan desimal.

double

Menyimpan angka desimal dengan presisi lebih tinggi.

char

Menyimpan satu karakter.

string

Menyimpan teks.

bool

Menyimpan nilai true atau false.

06

INPUT

cout << umur;
07

OPERATOR

Operator Matematika

08

CONDITION

if else 

int umur = 18;

if (umur >= 18) {

    cout << "Dewasa";

}

else {

    cout << "Belum Dewasa";

}
09

CONDITION

switch 

int hari = 1;

switch (hari) {

    case 1:

        cout << "Senin";

        break;


    case 2:

        cout << "Selasa";

        break;


    default:

        cout << "Hari lainnya";

}

LEVEL 3

C++ Lanjutan

18

OOP

Class dan Object

Class adalah blueprint untuk membuat object. Object merupakan hasil dari sebuah class. 

class Mahasiswa {

public:

    string nama;

};


int main() {

    Mahasiswa mhs;

    mhs.nama = "Opal";

    cout << mhs.nama;

}
19

OOP

Constructor 

class Mahasiswa {

public:

    string nama;


    Mahasiswa() {

        nama = "Opal";

    }

};
20

OOP

Inheritance

Inheritance memungkinkan sebuah class mendapatkan sifat dari class lainnya. 

class Hewan {

public:

    void suara() {

        cout << "Suara Hewan";

    }

};


class Kucing : public Hewan {

};
21

OOP

Polymorphism

Polymorphism memungkinkan method yang sama memiliki perilaku yang berbeda. 

class Hewan {

public:

    virtual void suara() {

        cout << "Suara Hewan";

    }

};


class Kucing : public Hewan {

public:

    void suara() {

        cout << "Meong";

    }

};
22

OOP

Encapsulation

Encapsulation digunakan untuk melindungi data dalam sebuah class. 

class Akun {

private:

    string password;


public:

    void setPassword(string p) {

        password = p;

    }

};
23

FILE

File Handling

C++ dapat digunakan untuk membaca dan menulis data ke dalam file. 

#include <fstream>

ofstream file;

file.open("data.txt");

file << "Halo Dunia";

file.close();
