LEVEL 1

PHP Dasar

01

PENGENALAN

Apa Itu PHP?

PHP adalah bahasa pemrograman yang digunakan terutama untuk membuat website dinamis. PHP berjalan di sisi server sebelum hasilnya dikirim ke browser pengguna.

02

DASAR PHP

Penulisan PHP

Kode PHP ditulis menggunakan tag <?php dan ditutup dengan ?>. 

<?php

echo "Hello World";

?>
03

OUTPUT

echo

Perintah echo digunakan untuk menampilkan teks atau data. 

<?php

echo "Halo Dunia";

?>
04

VARIABLE

Variabel

Variabel digunakan untuk menyimpan data. Pada PHP, variabel selalu diawali dengan tanda $. 

<?php

$nama = "Opal";

echo $nama;

?>
05

DATA TYPE

Tipe Data

string

Menyimpan teks.

integer

Menyimpan bilangan bulat.

float

Menyimpan bilangan desimal.

boolean

Menyimpan nilai true atau false.

array

Menyimpan banyak data.

null

Variabel tidak memiliki nilai.

06

OPERATOR

Operator Matematika

<?php

$a = 10;
$b = 5;

$hasil = $a + $b;

echo $hasil;

?>
07

CONDITION

if else

<?php

$umur = 18;

if ($umur >= 18) {

    echo "Dewasa";

} else {

    echo "Belum Dewasa";

}

?>
08

CONDITION

switch

<?php

$hari = 1;

switch ($hari) {

    case 1:
        echo "Senin";
        break;

    case 2:
        echo "Selasa";
        break;

    default:
        echo "Hari lainnya";

}

?>
🔵

LEVEL 2

PHP Menengah

09

ARRAY

Array

<?php

$buah = [
    "Apel",
    "Mangga",
    "Jeruk"
];

echo $buah[0];

?>
10

ARRAY

Associative Array

Associative array menggunakan nama atau key untuk menyimpan data. 

<?php

$mahasiswa = [

    "nama" => "Opal",
    "umur" => 18

];

echo $mahasiswa["nama"];

?>
11

LOOP

for Loop

<?php

for ($i = 1; $i <= 5; $i++) {

    echo $i;

}

?>
12

LOOP

while Loop

<?php

$i = 1;

while ($i <= 5) {

    echo $i;

    $i++;

}

?>
13

LOOP

foreach

<?php

$buah = [

    "Apel",
    "Mangga",
    "Jeruk"

];

foreach ($buah as $item) {

    echo $item;

}

?>
14

FUNCTION

Function

<?php

function salam() {

    echo "Halo Dunia";

}

salam();

?>
15

FUNCTION

Parameter

<?php

function salam($nama) {

    echo "Halo " . $nama;

}

salam("Opal");

?>
16

FORM

Form dan $_POST

PHP dapat menerima data dari form HTML menggunakan method POST. 

<form method="POST">

    <input type="text" name="nama">

    <button type="submit">
        Kirim
    </button>

</form>


<?php

$nama = $_POST["nama"];

echo $nama;

?>

PHP Lanjutan

17

FILE

Include dan Require

<?php

include "header.php";

require "database.php";

?>
18

SESSION

Session

Session digunakan untuk menyimpan data pengguna selama pengguna masih berada dalam sesi website. 

<?php

session_start();

$_SESSION["nama"] = "Opal";

echo $_SESSION["nama"];

?>
19

COOKIE

Cookie

<?php

setcookie(

    "nama",

    "Opal",

    time() + 3600

);

?>
20

FILE

File Handling

<?php

$file = fopen(

    "data.txt",

    "w"

);

fwrite(

    $file,

    "Halo Dunia"

);

fclose($file);

?>
21

OOP

Object-Oriented Programming

PHP mendukung Object-Oriented Programming atau OOP untuk membuat program lebih terstruktur.

22

OOP

Class dan Object

<?php

class Mahasiswa {

    public $nama;

}


$mhs = new Mahasiswa();

$mhs->nama = "Opal";

echo $mhs->nama;

?>
23

DATABASE

Database MySQL

PHP sering digunakan bersama database MySQL untuk menyimpan dan mengambil data dari website. 

<?php

$conn = mysqli_connect(

    "localhost",

    "root",

    "",

    "database"

);

?>
